# 本轮复盘与第8轮选将建议

账号：bixianjue。期次：s2-2026-09-09。核定日期：2026-09-11。

结论：优先第一组黄月英＋夏侯惇。先将第二队改为诸葛亮、黄月英、法正，提高两队获胜的机会；夏侯惇作为第三队重构候选，不为上新将强行拆阵。此为建议，用户尚未确认选取，未新增到已选仓库、未覆盖当前阵容、未改常规库存。

- 本次13图：9张战斗明细、1张三场总览、3张第8轮候选。原图复制到本期证据目录，保留旧演武证据。
- 总览（图2）：州内小组赛、陇右赛区、02组，可见对书遥、云间梧、星丨白水均2:1；可见小局6:3。用户明确本轮晋级。不是完整赛程，不能据此推算全部对手结果。
- 图4、8显示的是单段平局。此前机制确认平局续战，因此不记最终败或最终平，也不由总览反推出是哪支队伍取得后续小局。
- 图8、9对手昵称生僻字暂转写为“桦舲戍胡尉”，不用于实体匹配，以图片编号为准。
- 汇总战法伤害不包含所有普通攻击，不能当全场总伤害；战损不同于兵力下降。指挥/被动×1不代表只生效一次，伤害0不代表无辅助效果。
- 卡面15%、28%、7%、7%、24%、4%仅抄录显示，含义未知，不称胜率、红度或强度。
- 对手战法不等于我方已拥有。本期无韬略，不使用任何专属书加成；公开手游攻略仅辅助核对技能方向，不覆盖Steam本期实测。

## 第二队：问题不只是缺输出

这4张明细均为诸葛亮、黄盖、法正的雁形阵，黄盖已带固若金汤＋如有神助，与上次纠正后的配置相符。不能再用“黄盖没带如有”解释此次失败。

| 6 | 诸葛亮、马超、张飞 | 负 | 0 / 17137 | 0 / 0 | 2758 / 1400 |

| 10 | 大乔、黄盖、周瑜 | 负 | 0 / 21512 | 0 / 0 | 3850 / 5751 |

1. **治疗对局：打得出伤害，但不能有效消耗对手。** 图4我方可见战法伤害30066，对方28384，不能解释成我方总输出更高；但这至少说明不能只怪“没输出”。双方可见恢复3801对11764，差7963，确有显著续航差距。图8恢复差只有944，更主要的观察是对方周瑜临机制胜单项22782，而我方黄盖只有3516。两场平局不能套同一个原因。
2. **爆发对局：苦肉低发动使减伤和借刀输出一起不稳定。** 图6、10黄盖苦肉均0次；如有神助不能保证发动，也不免控。图10对手黄盖3次9427，我方0次，说明同一武将的发动和环境差异很大，不等于黄盖本身不能用。缺少逐回合日志，不能断言是技穷、震慑、早死还是概率失败。
3. **诸葛亮仍是有效核心。** 图6草船＋谈笑10285，图10合10539；问题是另外两人的有效输出与持续作战没跟上。图6敌方恢复还低于我方，因此这场不能简单归为“奶量不足”，需要提高存活时间及削弱敌方爆发。
4. **法正承压仍是风险，阵型不是已证实的唯一病因。** 两张平局均是法正、黄盖归零，诸葛独活；无法从结果图恢复死亡先后。延续用户既定雁形，不把敌人常用箕形当作必胜证据。

- **不是甘宁每场都没发动。** 图9攻其3次仍大败；张辽三项可见战法伤害合3658，甘宁两项合2966，而敌吕布横扫千军＋兵贵神速17608。敌方同时有恢复和保护，不能把吕布的成绩归于一张武将卡，也不能拿我方现有战法直接复制对面。
- **也不是第三队完全没有战斗力。** 图5张辽三项13041、甘宁两项5406，胜后剩17510。说明现有输出链能工作；图3、9中攻其同为3次却只有3353、2190，发动次数不是伤害与胜负的充分解释。目标、防护、兵力、控制时点的具体影响需日志。
- **治疗与多核输出压制是警讯。** 图7敌吕蒙、周瑜、陆逊自带伤害合20068，图1陆逊自带15720；仅靠甄洛束手无策不能据汇总证明已限制全部主核。图9对方仍三人高兵力，属于明显失利，不只是差一次发动。
- **配置分开处理。** 图1、3、5为甄洛出其不意版；图7、9为任人唯贤版。不能把两版合并评价，不能由图片上传顺序认定当前锁定版本。任人×0或×1只说明该图发动统计，不能由两个不同对手败局证明换战法必然变差。

## 为什么选第一组

| 候选组 | 主要价值 | 本期取舍 |
| --- | --- | --- |
| 1 黄月英＋夏侯惇 | 黄月英补群体恢复与奇数回合增伤；夏侯惇补前排反伤和降低敌人伤害的选项 | 首选。先改善第二队的稳定性，不依赖后两轮抽到指定金战法 |
| 2 郭嘉＋张宝 | 提供新的谋略输出/控制构筑方向 | 不是弱将，但没有直接补齐当前保护缺口；郭嘉主打主动学习战法，还会与现有法队竞争资源 |
| 3 袁绍＋吕布 | 增加多段输出与物理爆发上限 | 进攻备选。不能当成同时获得对手曹操、横扫千军、兵贵神速、无难之志和舍生取义，当前仓库不支持原样照抄 |

黄月英的木牛流马机制已有本期截图核验：奇数回合全队增伤、偶数回合全体恢复。诸葛与法正可继续输出，新增恢复不依赖黄盖那次50%主动是否启动；诸葛、法正、黄月英组成三蜀，并有诸葛与月英的缘分。阵营属性10%不直接算成最终伤害10%，缘分受到治疗8%只归缘分成员，不给法正套用。

代价同样明确：移除苦肉计会损失其爆发与火攻来源；木牛不是免控或驱散，也不能无视禁疗。目的为提高可用性，不保证每个对手都比原阵强。

夏侯惇刚烈的前排反伤及削弱敌方输出方向可由[配将专栏介绍](https://www.taptap.cn/moment/529302996719243015)交叉参考。原文“完全不怕控制”不能照抄为本期全面免控；本建议只说其被动触发不依赖主动发动。未核验Steam当前精确系数，不纳入数值模拟。

[郭嘉介绍](https://www.taptap.cn/moment/532552089834883186)及[袁绍介绍](https://www.taptap.cn/moment/529648868875306686)仅支持技能方向判断；[官方账号收录的吕布卡包分析](https://www.bilibili.com/read/cv35765881/)也指出主动触发波动和配套需求。均不采纳文中的韬略、装备、后续赛季配置或发动率数值作为本期已核参数。

## 第8轮后的可执行过渡方案

执行前提：用户确认第一组且游戏允许配置调整；不视为已点击、已上阵。

第一队孙权、小乔、陆逊及其六战法暂不动；本次没有第一队明细，不宣称已经证明无短板。

第二队保留雁形：

| 站位 | 武将 | 学习战法 |
| --- | --- | --- |
| 前排 | 黄月英 | 固若金汤＋任人唯贤 |
| 前排 | 法正 | 狂风大作＋断敌粮道 |
| 后排 | 诸葛亮 | 胜敌益强＋谈笑诛心 |

月英接原黄盖位置，固若保统率与嘲讽，任人补统率和增伤，不给指挥型木牛配如有神助来提高其发动。法正保留负面战法以供谈笑利用。黄月英前排要承伤，同时智力影响治疗与增伤，先保留加点未定，不在缺面板时宣称全统或全智为最优。固若从第2回合起才有内部嘲讽判定，前期存活依旧要验证。

第三队在后两轮选卡前先保留甄洛、张辽、甘宁的方圆阵。若甄洛当前带任人，改回出其不意，把唯一任人给月英；这样过渡三队9将、18个学习战法不重复。如有神助腾为可调资源，不等于必须马上给某个被动将。

夏侯惇不强行立刻上阵。候选为夏侯惇＋甄洛前排、甘宁后排的方圆阵，用夏侯替张辽换保护，但会牺牲张辽传递输出，需要后两轮补防护战法才值得进一步定案。固若已给第二队，不能再给夏侯；避其锐气与横征暴敛在第一队，不默认拆走。如改为保留张辽，仍需让张辽处于前排才能计入传递伤害条款。

第9/10轮候选尚未提供，类型与内容未知。下一步按实际候选优先比较减伤、免控/净化、稳定恢复与现有核心的适配性，不预先承诺能拿到指定战法。现在确定的是第8轮选第一组的方向，不把有条件构筑写成已验证的最终阵容。
