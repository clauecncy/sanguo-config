# 第5轮建议第二组

建议烈火焚营、指点乾坤、舍生取义。仅推荐，尚未实际选择；当前仍10将14战法，支援1将2战法未定。

核心是取得库存没有的指点乾坤。用户本期10级图确认50%主动，分别令武力最高单体对敌全体造成80%兵刃、智力最高单体对敌全体造成80%谋略。按实际两名输出者属性计算，不当成携带者自己打160%，不因田丰/黄月英适配标签推定未知机制。可在最终阵容中考虑黄盖、黄月英或田丰承载，最高属性归属和行动顺序须届时核对。

第一组忘私相助很适合补前排受击治疗，也有上智为间给郭嘉，但库存已拥有忘私及破军，可以保留战法支援机会；不能假定它们已支援或完全免费取得。此轮先取不能通过库存补齐的关键借刀，下一轮再核蓄势、忘私等拖回合配套。不是为了火攻队而锁死周瑜支援。

第二组烈火补谋略主动与火攻来源，舍生提供前2回合全队30%连击和最高武力单体清醒，携带者自身缴械2回合，应安排不依赖普攻的承载者。舍生不是每支队都必带，若最终配套不足可不用，不能为了凑三张强行改变邓关夏核心。

第三组以静新图确认其保护自身及随机一名友军，而非仅自身；奇数回合无法普攻、减少兵刃/普攻/追击伤害20%（受统率影响），偶数回合无法主动、减少谋略/主动伤害20%（受统率影响）。它可保护指挥被动承载者，但不能同时声称该人偶数回合仍能发动主动治疗或指点；不同减伤类别也不擅自相加成40%。奇门需准备1回合，知人保护最高智力目标，整组更偏防护和准备谋略；本轮优先补输出手段，而不是继续堆防护。

选择是定性构筑比较，不使用选取率或跨红度烈火倍率推算胜率。指点与以静两项新完整详情已同步公共库，旧低等级指点观察保留。
