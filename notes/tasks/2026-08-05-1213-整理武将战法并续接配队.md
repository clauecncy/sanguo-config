# 整理武将战法并续接配队

## 1. 原始需求

用户提供旧会话 ID，要求把已有武将、战法整理成 Markdown；后续获得实时更新时继续更新；确认阵型可以重复使用，并要求续接上次配队推荐。

## 2. 我的理解

从旧会话最近截图恢复账号库存，建立长期 Markdown 资料库；保持武将和战法跨队不重复，只取消阵型互斥限制，并据此修正三队阵型与战法分配。

## 3. 执行步骤

1. 读取旧会话最近与更早的相关轮次。
2. 逐张核对最近 12 张武将、战法和现有阵容截图。
3. 查阅 2026-08-05 可检索的 Steam 上线信息和近期攻略，确认仍应按初始服/S1阶段处理。
4. 建立库存、配队、固定项目笔记和本地 Git。
5. 校验数量、链接和 Git 工作区状态。

## 4. 涉及的业务逻辑

- 最近截图优先于旧回复和联网攻略。
- 武将、战法不跨队重复，阵型允许重复。
- 主队看稳定性和养成程度，二队保完整联动，三队使用剩余资源。

## 5. 修改前状态

项目目录为空，无 Git、无 Markdown 库存、无项目笔记。

## 6. 关键决策

- 以 2026-08-05 最近截图为当前快照，记录 17 名武将和 36 个战法。
- 一队、二队同时使用鱼鳞阵，落实“阵型可重复使用”。
- 三队采用黄盖、小乔、甘宁，默认箕形阵；雁形阵作为偏输出切换。
- 对图片无法证明的装备、坐骑和完整韬略库存不作推断。

## 7. 具体修改点

- 新建 `武将战法库存.md`，记录名称、等级、当前携带者和当前两队截图配置。
- 新建 `阵容推荐.md`，给出三队站位、战法、阵型、属性和资源顺序。
- 新建固定项目笔记与 `.gitignore`。

## 8. 验证结果

- 武将计数：17 名，与最近两张武将库截图一致。
- 战法计数：36 个，按截图连续列表核对为金色 7 个、紫色 29 个。
- 当前一队与二队的武将、战法、等级均与截图一致。
- 推荐中阵型允许复用，武将与战法分配无跨队重复。

## 9. 产出物

- `武将战法库存.md`
- `阵容推荐.md`
- `notes/项目说明.md`
- `notes/业务逻辑.md`

## 10. 回滚方法

通过本任务本地 Git 提交查看全部新增文件；需要回滚时创建反向提交，不删除 `notes/` 或 `.git/`。
