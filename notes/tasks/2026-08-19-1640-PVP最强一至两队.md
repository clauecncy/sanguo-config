# PVP 最强一至两队配置

> 2026-08-19 纠正：本记录初版误读了尚未写入项目的上午库存，使用了 2026-08-12 的 22 将、43 战法，且没有按用户提供的 S1 梯队图校验二队。后续已以 28 将、49 战法重算；最终结论改为貂梁盾优先、铜雀弓第二，徐盛 + 孙权 + 甘宁撤回。

## 1. 原始需求

用户询问根据目前拥有的武将和战法，如何配出最强的一队或两队用于 PVP。

## 2. 我的理解

按账号最近确认的 Steam S1 常规库存配队，不混入演武活动临时仓库；分别给出资源只集中一队和两队同时出战的方案，武将与战法跨队不得重复。

## 3. 执行步骤

1. 阅读项目固定文档、最近库存和既有阵容方案。
2. 核对 22 名金将、43 个金紫战法及新增武将、战法。
3. 复核铜雀弓和徐盛孙权甘宁的 S1 体系逻辑。
4. 重写当前 PVP 推荐，检查两队武将和战法去重。
5. 更新业务逻辑、变更记录并建立本地 Git 版本。

## 4. 涉及的业务逻辑

- 常规账号库存与演武活动仓库分开。
- 只考虑金色武将和金、紫战法。
- 两队武将、战法互不重复，阵型可以重复。
- 铜雀弓依靠负面状态、治疗与谋略追加伤害闭环。
- 孙权携带非主动战法服务全队连击，甘宁使用追击承担输出。
