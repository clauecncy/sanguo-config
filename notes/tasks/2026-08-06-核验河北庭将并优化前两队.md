# 核验河北庭将并优化前两队

## 1. 原始需求

用户提供河北庭将 Steam 缘分截图，并询问在武将和战法等级可免费重置、不考虑重置成本的前提下，一队、二队如何调整或优化。

## 2. 我的理解

需要先把河北庭将激活条件和效果升级为 Steam 已核，再用账号已有金将、金/紫战法及准确技能机制重新分配前两队。当前等级不构成沉没成本，但未知升阶、韬略和装备不能假定相同。

## 3. 执行步骤

1. 保存缘分截图并更新数据库固定覆盖。
2. 查询本地数据库中的武将四维、自带战法和已有战法完整效果。
3. 联网复核 S1 成熟阵容作为次级参考。
4. 形成推荐重组方案、保守替代方案和河北庭将定位。
5. 重建数据库并验证，更新任务与变更记录。

## 4. 涉及的业务逻辑

- 河北庭将任意 2 名成员同队激活，缘分武将武力 +20。
- 武将和战法等级可免费重置，因此推荐按技能协同而非当前等级排序。
- 武将、战法跨队不重复；阵型可重复。
- Steam 截图优先于网络 S1 配队参考。

## 5. 修改前状态

- 河北庭将的激活人数与效果仍为待 Steam 核验。
- 一队是赵云 + 貂蝉 + 大乔，二队是黄巾三兄弟。
- 攻其不备效果摘要误写为缴械，实际截图与完整正文均为技穷，已有技穷时概率震慑。

## 6. 关键决策

- 河北庭将当前可激活，但不直接等同于前两队升级：颜良、文丑均为追击输出，仍缺稳定前排和治疗。
- 主推荐将一队重组为徐盛 + 大乔 + 孙策；二队保留黄巾武将，只将张梁的克敌如风换成坚壁清野。
- 保留赵云原队的小改方案，避免在升阶/韬略未知时把重组结论说成绝对强度。

## 7. 具体修改点

- 将河北庭将写入同步脚本固定覆盖：2 人激活，缘分武将武力 +20，状态为 Steam 已核；验证脚本新增对应断言。
- 修正攻其不备摘要：施加的是技穷，不是缴械；目标已有技穷时才有 50% 概率震慑。
- `阵容推荐.md` 将一队重组为徐盛 + 大乔 + 孙策；二队保留黄巾三将并将张梁改为坚壁清野 + 揭竿而起。
- 给出保留赵云队的小改方案，以及颜良 + 文丑作为追击第三队的试配方案。
- 重新分配前三队 18 个战法，确保账号均已拥有且三队间不重复。

## 8. 验证结果

- Python 语法与 Markdown 差异检查通过；SQLite `integrity_check=ok`。
- 河北庭将数据库记录为 3 名成员、2 人激活、武力 +20、Steam 已核。
- 推荐前三队共使用 18 个互不重复战法，数据库确认 18 个均为账号已有。
- 账号品质越界为 0，武将四维及战法正文无缺失。
