# 更新金将与未装备战法库存

## 1. 原始需求

用户提供最新武将库与未装备战法截图，要求更新长期库存资料。既定范围为只考虑金色武将、金/紫战法、紫色或专属韬略。

## 2. 我的理解

最新武将截图覆盖账号金将的当前等级和编队，并新增颜良；下排紫将不进入配队库存。战法截图是未装备列表，应在保留此前已确认装备战法的基础上合并新增条目，不能把局部列表误当成全量库存。

## 3. 执行步骤

1. 保存六张原始截图副本到项目证据目录。
2. 更新账号库存种子和 Markdown 库存。
3. 为新增战法补充全局效果摘要与状态联动。
4. 重建并验证 SQLite 数据库。
5. 更新覆盖率、业务逻辑与变更记录并创建本地提交。

## 4. 涉及的业务逻辑

- 只统计截图中的金色武将；紫将不进入配队候选。
- 金/紫战法均可记录；本次截图明确为未装备战法，所以携带者写空。
- 局部截图采用增量合并，不删除此前已核但本次未显示的条目。
- 新截图的等级、编队与品质优先于旧库存。
