# 项目说明

## 项目目的

记录《三国：谋定天下》Steam 初始服账号已拥有的武将、战法、阵型规则和配队建议，作为后续对话的长期资料。获得新武将、战法或版本实时信息后，在同一项目内追加更新。

## 输入和输出文件

- 输入：用户截图、用户明确说明、必要时查询到的当前版本资料。
- 核心库存：`武将战法库存.md`
- 当前建议：`阵容推荐.md`
- 业务规则：`notes/业务逻辑.md`
- 变更历史：`notes/变更记录.md`

## 运行方法

本项目为 Markdown 资料库，无需运行程序。直接打开根目录下的 Markdown 文件即可查看。

## 系统兼容性

Markdown 文件与操作系统无关，Windows、macOS、Linux 均可阅读；游戏账号当前为 Windows Steam 版初始服。

## 依赖和已知限制

- 无软件依赖。
- 武将等级、战法等级随养成变化，必须以最近截图为准。
- 游戏平衡调整和赛季规则可能变化；联网资料只作为辅助，若与游戏内截图冲突，以当前账号游戏内显示为准。
- 当前库存不含装备、坐骑和完整韬略库存。
