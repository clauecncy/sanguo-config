# 项目说明

## 项目目的

记录《三国：谋定天下》Steam 初始服账号已拥有的武将、战法、阵型规则和配队建议，并维护可计算的 SQLite 基础数据库，作为后续对话的长期资料。获得新武将、战法、面板或版本实时信息后，在同一项目内追加更新。

## 输入和输出文件

- 输入：用户截图、用户明确说明、必要时查询到的当前版本资料。
- 核心库存：`武将战法库存.md`
- 战力规则库：`战力机制资料库.md`，记录缘分、阵型、自带战法和通用战法效果，并标注版本可信度。
- 当前建议：`阵容推荐.md`
- 第三方 S1 梯队参考：`S1强队模板库.md`
- SQLite 数据库：`data/三国谋定天下_Steam_S1.sqlite3`
- 数据库说明与覆盖率：`数据库说明.md`、`data/覆盖率报告.md`
- 同步与验证脚本：`scripts/sync_game_data.py`、`scripts/verify_database.py`
- 业务规则：`notes/业务逻辑.md`
- 变更历史：`notes/变更记录.md`

## 运行方法

日常查看可直接打开 Markdown。需要同步网络数据时，按 `数据库说明.md` 运行 Python 脚本；数据库使用 SQLite，无需安装服务。

## 系统兼容性

Markdown 文件与操作系统无关，Windows、macOS、Linux 均可阅读；游戏账号当前为 Windows Steam 版初始服。

## 依赖和已知限制

- 同步脚本使用项目运行环境中的 Python 3、标准库和 `lxml`；已有数据库可脱离网络直接查询。
- 武将等级、战法等级随养成变化，必须以最近截图为准。
- 游戏平衡调整和赛季规则可能变化；联网资料只作为辅助，若与游戏内截图冲突，以当前账号游戏内显示为准。Steam S1 与移动端历史版本不默认等同。
- 当前库存不含装备、坐骑和完整韬略库存。
- 公开成长值只显示两位小数，等级面板推算可能相差 1 点；速度阈值优先用 Steam 实测面板。
- 暂无可信的 Steam S1 全量韬略推荐来源，数据库保留对应表和缺口状态，避免跨赛季猜填。

- 战法等级实测：data/tactic_level_observations.json保存结构化种子，SQLite表	actic_level_observations保存指定等级、发动率、原始效果、结构化效果与截图来源；同步重建不会丢失。
