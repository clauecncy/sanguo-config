## 使用规则

1. 参考库只回答“当前 S2 有哪些经实战验证的阵容思路”。
2. 实际配置阵容、战法分配与演武时，才核对本地库存、武将等级、进阶、兵种适性、战法等级及战法占用。
3. 参考图文字密集；需要输出某一队的精确配置时，应以原图局部高清内容或游戏内说明复核。

## 完整字段与符号规范


每支队伍除梯度、阵型、武将、战法外，还必须逐将记录以下字段：

- 站位。
- S2 进阶兵种，如重盾、轻骑、长弓。
- 进阶兵种的两项兵种专精。
- 加点及速度链。
- 韬略组合。
- 装备/坐骑推荐属性。

已确认示例：`追击辽一字阵`使用轻骑、重盾、长弓；对应专精为`乘胜/追击`、`屹然/不动`、`袍泽/同心`。

常规参考库完整保存上述字段。演武不使用坐骑、装备和韬略；进阶兵种和兵种专精仍须以本期活动规则与界面核对，不能因演武模式而从参考模板省略。

## 战法与韬略符号口径

- `A>B`：优先使用 A，缺少时以 B 替代。
- `A/B`：A 与 B 同级二选一。
- 黄色底的韬略文字均记为金色韬略；`金书`表示金色韬略，`上卷`、`下卷`表示金色韬略的上下卷。
- `治国`、`东观`等黄色文字同样属于金色韬略。
- 紫色底的韬略文字记为紫色韬略。金色与紫色都属于韬略，不把黄色栏误记为来源或备注。
