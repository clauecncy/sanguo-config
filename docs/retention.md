# 资料保留与清理

- 个人库存只维护 `inventory.json`，报告覆盖更新，不生成多个库存 JSON 或 SQLite 版本。
- `evidence/current/` 只保留最新一次成功更新的整批原始截图及其哈希清单；新图片更新失败时不清理旧批次，文字更新不清理现有截图。
- `evidence/incoming/` 用于本次图片和更新 JSON。成功后删除本次显式传入的临时文件；失败时保留以供修正重试。项目外输入只读，不删除。
- 已完成迁移的旧库、旧库存、过时交接文档、停用脚本、重复 OCR 原稿可以删除；只保留校验摘要，不再保存它们的完整副本。
- 公共游戏资料的重建源、尚需核验的来源、当前配将参考和各期演武资料有独立用途，继续保存。库存清理不能误删演武战报或公共数值截图。
- 现有 Git 历史与 stash 不属于本次材料清理范围。
