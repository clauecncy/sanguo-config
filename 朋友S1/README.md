# 朋友 S1 资料库

此目录与项目根目录的个人账号资料完全隔离，记录朋友的 S1 截图库存与当前演武阵容。

## 文件

- `data/account_inventory.json`：截图可确认的账号库存种子，含 46 名金将、6 名紫将与 23 个金/紫通用战法。
- `data/三国谋定天下_朋友_S1.sqlite3`：以项目既有的 S1 全局资料为参考底库，叠加本目录独立的账号拥有记录。
- `演武大赛/当前阵容.md`：本次演武三支部队的界面快照。

## 数据口径

- 截图展示总数为 73，但本次仅录入三张武将截图中姓名、阵营、品质及红标可清晰辨认的 52 名武将（46 金、6 紫）；卡面标有“重复武将”的项目不重复计数。
- 战法仅录入仓库和演武资源栏中可清晰辨认的通用战法；金/紫品质按卡框与截图标签保存，战法红度截图未展示，数据库中保持未知。
- 武将等级为截图快照信息，不写入常规库存层；演武中显示的等级、支援状态与常规库存互不反推。
- 本次没有保留用户原始截图副本；证据来源为 2026-09-10 对话中提供的 8 张游戏内截图。

## 更新与校验

数据库由 `scripts/create_friend_s1_database_v2.py` 从库存种子创建，脚本不会覆盖已存在的朋友数据库。需要重建时，先保留旧版 SQLite 文件，再运行：

```powershell
& <项目Python路径> scripts/create_friend_s1_database_v2.py
```
